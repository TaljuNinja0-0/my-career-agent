AI 커리어 에이전트 PRO 사용법 상세 안내

1
Gemini API 키 입력 & 안전한 15 RPM 대기 보호

Google AI Studio에서 발급받은 무료 Gemini API 키를 상단 입력창에 넣거나 .env 파일로 자동 로드할 수 있습니다. 무료 API 분당 15회(15 RPM) 한도 보호를 위해 사전 5초 대기 및 429 감지 시 지수 백오프 자동 대기 기능이 작동합니다.

2
자기소개서 입력 & 1-Click 샘플 3종 테스트

자신의 이력서를 자유롭게 입력하거나 상단 샘플 A(컴공 백엔드), 샘플 B(통계 데이터), 샘플 C(경영 IT전환) 버튼으로 1초 만에 시연할 수 있습니다. 💡 특히 샘플 C(비개발자)는 억지로 개발 직무를 밀지 않고 IT기획/마케팅 등 가능한 직무를 수집합니다.

3
에이전트 보유 역량 확인 (Ask 인터랙션)

에이전트가 1단계로 자소서에서 보유 역량을 파악한 후, Ask 다이얼로그 카드가 열려 "이 역량이 맞으신가요?" 묻습니다. 사용자가 역량을 확인하거나 추가 기술을 작성한 뒤 [확인하고 계속 진행하기]를 누르면 공고 수집이 계속됩니다.

4
Google 실시간 공고 수집 & 출처 원문 검증

searchJobs 및 searchCompanyInfo 도구를 통해 Google 실시간 채용 정보와 기업 연봉/복지를 검색합니다. 수집된 모든 공고 카드에는 Google Grounding Metadata 기반의 실제 원문 링크가 첨부됩니다.

5
Agent Live Logs 관전 & Chart.js final 컨설팅 보고서

단번에 답만 나오는 챗봇이 아니라, 우측 터미널 패널에서 에이전트의 사고(THOUGHT)와 실제 구글 검색어(TOOL_CALL)를 관전할 수 있습니다. 수집 완료 후 JS 적합도 계산 점수 차트와 7대 세부 커리어 보고서가 완성됩니다.
